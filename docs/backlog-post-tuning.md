# Backlog — after the tuning window (verified against main @ 01bbe2b, 2026-09-18)

This is a **backlog, not a change list**. Nothing in this file is implemented; every "Proposed fix" is a one-line suggestion for the owner to accept, reject or reorder.
Standing order: **no code changes, no protocol/prompt changes, no "never delete" feature during the 7-day tuning window (Sep 18–25, 2026).** The owner decides what to pick up when the window ends.
Trigger for this audit: on the evening of Sep 17 (UTC) the library forums emptied twice — `purge:scout` (64 scout videos, intended) and then boot jobs `["purge:saved","import"]` (79 saved-collection videos / 162 forum threads deleted and re-queued for a stricter classifier) with no warning to the owner.
Every row below was re-checked in the current code; two audit findings that could only be partly confirmed are listed at the end, together with new findings noticed while reading. Line numbers are from the files as they are on `main` today.
Severity: **P0** = must be fixed before the scraper/import is unleashed at full scale · **P1** = will bite within weeks · **P2** = paper cut / hygiene.
